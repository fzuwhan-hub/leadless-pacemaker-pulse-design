# Channel-Driven Equalizer-Free Pulse Design for Leadless Pacemakers

Data and verification scripts accompanying the manuscript *Channel-Driven Equalizer-Free Pulse Design for Leadless Pacemakers: LPTV Modeling and Pareto Optimization*.

- [Waveform optimization](waveform-optimization/) contains the objective values for Figures 5 and 6, the parameter-to-shape mapping, and the script to verify Pareto membership and the nominal Knee Point.
